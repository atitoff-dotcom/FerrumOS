# Мгновенный Hot-Swap за 15 мс

Одна из ключевых возможностей FerrumOS — **развертывание логики на лету (Live Hot-Swap)**. Вы можете обновлять код на работающем микроконтроллере менее чем за 20 миллисекунд по USB или Wi-Fi **без перезагрузки чипа**.

---

## ⚡ Проблема традиционной разработки микроконтроллеров

В стандартных платформах (C++, Arduino, MicroPython):
1. Каждое изменение кода требует сборки или линковки тяжелого бинарника.
2. Прошивка по UART/USB занимает от 10 до 45 секунд.
3. Микроконтроллер уходит в аппаратный перезапуск (`RESET`).
4. Рвутся соединения Wi-Fi, сбрасывается сессия MQTT, датчики начинают долгий цикл калибровки и прогрева заново.

Это делает отладку датчиков, калибровку ПИД-регуляторов и поддержку устройств в продакшене мучительно долгой.

---

## 🚀 Как устроен Hot-Swap в FerrumOS

Ядро FerrumOS построено на реактивном микро-рантайме с разделением системного ядра и слотов задач:

```
[ FerrumOS Studio ]
       │
       │ 1. Компиляция в компактный байткод (3–5 мс)
       ▼
 [ Пакет USB / Wi-Fi ]
       │
       │ 2. Передача по Ferrum Wire Protocol (0xFE, 0xEE)
       ▼
 [ Микроконтроллер RISC-V ]
   ┌──────────────────────────────────────────────┐
   │ Ядро реального времени (Не перезагружается) │
   │ ├─ Стек Wi-Fi / радио (Соединение живо)      │
   │ ├─ Сессии TCP & MQTT (Не рвутся)             │
   │ └─ Состояния пинов и ШИМ (Без глитчей)       │
   │                                              │
   │ Слоты пользовательских задач:                │
   │ ┌──────────────────────┐                     │
   │ │ Слот А (Старый код)  │ ── Пауза ──► Сброс  │
   │ └──────────────────────┘                     │
   │ ┌──────────────────────┐                     │
   │ │ Слот Б (Новый код)   │ ◄── Свап и запуск!  │
   │ └──────────────────────┘                     │
   └──────────────────────────────────────────────┘
```

### Этапы обновления:
1. **Мгновенная компиляция**: Компилятор Studio транслирует скрипт в байткод за 3–5 миллисекунд прямо в памяти.
2. **Потоковый кадр**: Бинарный пакет передается по высокоскоростному проводу или сети.
3. **Атомарная подмена слота**: Ядро валидирует контрольную сумму, останавливает старый контекст, переключает указатель инструкций и стартует новый код.
4. **Непрерывность сети**: Сетевые сокеты, брокер MQTT и аппаратные таймеры продолжают работать без единого прерывания связи.
