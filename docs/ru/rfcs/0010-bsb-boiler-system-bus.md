## 🎯 1. Введение и Концепция «Большой Четверки»

В автоматизации индивидуального и промышленного отопления доминируют четыре цифровых интерфейса:

1. **OpenTherm (OT/+)**: Самый массовый открытый стандарт для настенных бытовых котлов (Baxi, Viessmann, De Dietrich, Ferroli, Thermex, Лемакс, Biasi).
2. **BSB / LPB / PPS (Siemens Albatros)**: Премиальные котлы и сложные многоконтурные котельные с каскадами, теплыми полами и гелиосистемами (Baxi Luna Platinum, Brötje, De Dietrich Innovens, контроллеры Siemens RVS/LMS).
3. **eBUS (Vaillant Group)**: Крупнейшая экосистема в ЕС и СНГ (газовые Vaillant, электрические Protherm Скат/Пантера/Медведь).
4. **EMS / EMS+ (Bosch Thermotechnology)**: Протокол концерна Bosch (Buderus Logamax, Bosch Gaz, Junkers, Nefit).

### Архитектурная цель
Скрыть физические и протокольные различия низкого уровня за **единой полиморфной доменной моделью котла (`BoilerDevice`)**. 

Для разработчика автоматизации на JavaScript разница между Baxi на OpenTherm, Buderus на EMS, Protherm на eBUS и Brötje на BSB сводится **исключительно к одной строке инициализации шины**. Вся последующая бизнес-логика (уставки, ночное снижение, погодозависимые кривые, бойлер, мониторинг аварий и виджеты SCADA) является **100% идентичной и переносимой**.

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │ 1. Прикладной слой: Modern Human-JS (Fluent API)                       │
 │    boiler.circuit(1).comfort(21.5).curve(1.24).mode('comfort');        │
 │    boiler.dhw().target(52.0).mode('eco');                              │
 │    const pressure = boiler.pressure();                                 │
 ├────────────────────────────────────────────────────────────────────────┤
 │ 2. Единая абстракция домена: BoilerDevice (Rust Core / Runner)         │
 │    [Circuits Manager]  [DHW Controller]  [Burner]  [Diagnostics/SCADA] │
 ├──────────────────┬──────────────────┬────────────────┬─────────────────┤
 │ BSB / LPB Driver │ OpenTherm Driver │  eBUS Driver   │   EMS Driver    │
 │ (4800 8E1 UART)  │ (1000 Baud RMT)  │ (2400 UART+Arb)│ (9600 UART+Brk) │
 └──────────────────┴──────────────────┴────────────────┴─────────────────┘
```

## 📐 3. Полная спецификация Human-JS API

В соответствии со стандартами FerrumOS, API строится **исключительно на цепочке методов (Fluent Chaining)**. Мутации свойств (`pin.prop = val`) и конфигурационные объекты в прикладных методах запрещены.

### 3.1. Инициализация аппаратной шины (Провайдеры)

Каждый провайдер шины возвращает стандартный унифицированный экземпляр `BoilerDevice`:

#### 1. BSB (Siemens Albatros / Baxi Platinum / Brötje)
```javascript
const boiler = BSB.bus(1)
    .pins(17, 16)                      // TX pin, RX pin
    .baud(4800)                        // 4800 для BSB/LPB (480 для PPS)
    .address(0x42)                     // Наш адрес (Сервисный шлюз)
    .target(0x00)                      // Адрес основного контроллера котла
    .location("Котельная")
    .system("Главный котел");
```

#### 2. OpenTherm (Baxi Eco Four / Viessmann / Ferroli / Thermex)
```javascript
const boiler = OpenTherm.bus(1)
    .in(19)                            // RX вход от компаратора токовой петли
    .out(18)                           // TX выход модуляции напряжения
    .pollInterval(1000)                // Период опроса мастера (1000 мс по стандарту)
    .location("Котельная")
    .system("Газовый настенный котел");
```

#### 3. eBUS (Vaillant / Protherm Скат, Пантера)
```javascript
const boiler = eBUS.bus(1)
    .pins(21, 22)                      // TX, RX
    .baud(2400)
    .address(0x10)                     // Master address (0x10 или 0x3F)
    .location("Котельная")
    .system("Электрокотел Protherm");
```

#### 4. EMS / EMS+ (Bosch / Buderus Logamax)
```javascript
const boiler = EMS.bus(1)
    .pins(4, 5)                        // TX, RX
    .baud(9600)
    .address(0x0B)                     // Сервисный ID шлюза (Service Key)
    .location("Котельная")
    .system("Buderus Logamax Plus");
```

### 3.2. Управление отопительными контурами: `.circuit(index)`

Контроллер может иметь один или несколько контуров (радиаторы, водяной теплый пол, вентиляция). 

#### Методы настройки и уставок (Fluent Chaining):
* `.comfort(temperature)` — задать комфортную (дневную) уставку в °C.
* `.reduced(temperature)` — задать экономную (ночную) уставку в °C.
* `.target(flowTemperature)` — прямая ручная уставка температуры подачи (для каскадов/буферов).
* `.curve(gradient)` — наклон отопительной кривой (эквитермическое регулирование, например `1.24`).
* `.parallel(offset)` — параллельный сдвиг отопительной кривой в °C (например `+2.0`).
* `.influence(factor)` — коэффициент влияния комнатной температуры на расчет подачи (`0.0` .. `1.0`).
* `.minFlow(temperature)` — ограничение минимальной температуры подачи (защита от конденсата).
* `.maxFlow(temperature)` — ограничение максимальной температуры подачи (защита стяжки теплого пола, например `45.0`).
* `.mode(modeString)` — установить режим контура:
  * `"auto"` — работа по внутреннему расписанию и кривой.
  * `"comfort"` — постоянное поддержание комфортной температуры.
  * `"eco"` — постоянный экономный режим.
  * `"protection"` — дежурный режим (защита от замерзания, +7 °C).
  * `"off"` — полный останов контура.
* `.emulateRoom(temperatureSource)` — включить эмуляцию комнатного термостата (QAA75/RC310) с передачей внешней фактической температуры в котел.

```javascript
// Настройка контура 1 (Радиаторы 2-го этажа)
boiler.circuit(1)
    .comfort(22.0)
    .reduced(18.5)
    .curve(1.30)
    .influence(0.8)
    .maxFlow(70.0)
    .mode("auto");

// Настройка контура 2 (Теплый пол 1-го этажа со смесителем)
boiler.circuit(2)
    .comfort(21.0)
    .reduced(19.0)
    .curve(0.65)
    .maxFlow(42.0)                     // Жесткая аппаратная защита стяжки пола
    .mode("comfort");
```

#### Методы чтения метрик контура (Getters):
* `.roomTemp()` — фактическая температура в помещении (°C, от комнатного датчика).
* `.flowTemp()` — фактическая температура подачи контура (°C).
* `.returnTemp()` — фактическая температура обратки контура (°C).
* `.valvePos()` — степень открытия трехходового смесителя в % (0% = закрыт, 100% = открыт).
* `.pumpState()` — статус циркуляционного насоса контура (`true` / `false`).

```javascript
const t1Flow = boiler.circuit(1).flowTemp();
const t2Room = boiler.circuit(2).roomTemp();
const pumpOn = boiler.circuit(2).pumpState();
```

### 3.3. Горячее водоснабжение (ГВС / Бойлер): `.dhw()`

Управление встроенным вторичным теплообменником или бойлером косвенного нагрева (БКН).

#### Методы управления (Fluent Chaining):
* `.target(temperature)` — целевая температура горячей воды (°C).
* `.reduced(temperature)` — сниженная температура в периоды отсутствия/ночью (°C).
* `.hysteresis(delta)` — дельта включения подогрева бойлера (например `5.0` °C).
* `.mode(modeString)` — режим ГВС: `"on"`, `"off"`, `"eco"`, `"auto"`.
* `.boost(state)` — форсированный разогрев бойлера вне расписания (`true` / `false`).
* `.antiLegionella(state)` — активация регулярного термического обеззараживания (нагрев до 65 °C).
* `.recirculation(state)` — принудительное включение насоса рециркуляции полотенцесушителей.

```javascript
// Конфигурация бойлера косвенного нагрева
boiler.dhw()
    .target(55.0)
    .reduced(40.0)
    .hysteresis(4.0)
    .antiLegionella(true)
    .mode("auto");

// Сценарий «Гости в доме»: форсированный прогрев бойлера
boiler.dhw().boost(true);
```

#### Методы чтения метрик ГВС (Getters):
* `.temp()` — текущая температура воды в бойлере (°C).
* `.flowRate()` — мгновенный проточный расход ГВС (л/мин, для двухконтурных котлов).
* `.pumpState()` — статус насоса загрузки бойлера (`true` / `false`).

### 3.4. Управление горелкой и мощностью: `.burner()`

Управление первичным теплогенератором (горелка, ТЭНы, инверторный компрессор).

#### Методы управления:
* `.maxModulation(percentage)` — ограничение максимальной мощности котла в % (0..100).
* `.minModulation(percentage)` — фиксация минимального порога модуляции.
* `.enable(state)` — программное разрешение/запрет розжига (`true` / `false`).

```javascript
// Ограничение мощности на 70% для экономии ресурса теплообменника
boiler.burner().maxModulation(70);
```

#### Метрики горелки:
* `.isFiring()` — состояние пламени горелки (`true` / `false`).
* `.modulation()` — текущая фактическая модуляция мощности (0..100%).
* `.operatingHours()` — суммарные моточасы наработки горелки.
* `.starts()` — количество циклов розжига (тактование).
* `.flameCurrent()` — ток ионизационного датчика пламени в мкА (диагностика чистоты электрода).

---

### 3.5. Общесистемные метрики и датчики

Методы быстрого доступа на уровне корневого объекта `boiler`:

* `.pressure()` — давление теплоносителя в контуре отопления (бар).
* `.outdoorTemp()` — температура уличного воздуха (°C).
* `.flueGasTemp()` — температура дымовых газов (°C, контроль КПД и тяги).
* `.faultCode()` — код активной ошибки котла (`0` при нормальной работе).
* `.isFault()` — флаг наличия аварийного останова (`true` / `false`).

```javascript
const p = boiler.pressure();
if (p < 0.8) {
    print(`ВНИМАНИЕ: Низкое давление теплоносителя: ${p} бар!`);
}
```

### 3.6. Реактивные события и аварии: `.on(event, handler)`

Драйвер котла генерирует события реального времени без необходимости непрерывного опроса в цикле:

```javascript
// Авария котла
boiler.on("fault", (code, message) => {
    print(`АВАРИЯ КОТЛА [${code}]: ${message}`);
    buzzer.alarm(true);
    telegram.notify(`Котловой блок остановился: Ошибка ${code} (${message})`);
});

// Падение давления в системе
boiler.on("pressureDrop", (val) => {
    print(`Тревога: давление теплоносителя упало до ${val} бар`);
});

// Событие розжига пламени
boiler.on("flame", (firing) => {
    print(`Горелка ${firing ? "зажглась" : "погасла"}`);
    SCADA.element("flame_icon").visible(firing);
});
```

### 3.7. Низкоуровневый доступ (Escape Hatches под каждый протокол)

Для доступа к специфичным сервисным меню и заводским регистрам, отсутствующим в стандартной абстракции, сохраняются специализированные методы:

```javascript
// --- OpenTherm Escape Hatch (по Data-ID) ---
const oemDiagnostic = boiler.openTherm.get(115);      // Чтение OEM Data-ID 115
boiler.openTherm.set(1, 45.5);                         // Прямая запись tSet (ID 1)

// --- BSB Escape Hatch (по номеру строки сервисной книги Siemens) ---
const solarPumpSpeed = boiler.bsb.get(3830);           // Строка 3830: Скорость насоса коллектора
boiler.bsb.set(710, 22.0);                             // Строка 710: Уставка комфорта контура 1

// --- eBUS Escape Hatch (по сервисному блоку Vaillant) ---
const yieldTotal = boiler.ebus.read("bai", "YieldTotal"); 

// --- EMS Escape Hatch (по типу телеграммы Buderus) ---
const ubaData = boiler.ems.readTelegram(0x18, 0x02);   // Чтение блока мониторинга UBA
```

## 💡 4. Практические сценарии автоматизации (Cookbook & Examples)

Все примеры построены по стандарту Fluent Chaining и могут исполняться как автономно на микроконтроллере (ESP32 / ESP32-C6), так и в составе распределенной сети FerrumOS.

### 4.1. Сценарий 1: Базовая погодозависимая котельная коттеджа (OpenTherm / Baxi)
*Оборудование*: Настенный двухконтурный котел Baxi Eco Four, уличный датчик температуры, радиаторная сеть.
*Задачи*: Ограничение тактования горелки, эквитермическая кривая, контроль минимального давления теплоносителя.

```javascript
// Инициализация шины OpenTherm
const boiler = OpenTherm.bus(1)
    .in(19)
    .out(18)
    .pollInterval(1000)
    .location("Котельная")
    .system("Главный котел");

// Ограничение мощности горелки на 65% для снижения тактования в межсезонье
boiler.burner()
    .maxModulation(65);

// Настройка радиаторного отопления по уличной кривой
boiler.circuit(1)
    .comfort(22.0)
    .reduced(19.0)
    .curve(1.25)
    .parallel(1.0)
    .minFlow(35.0)                     // Защита от образования конденсата в теплообменнике
    .maxFlow(70.0)                     // Предел температуры радиаторов
    .mode("auto");

// Конфигурация встроенного ГВС
boiler.dhw()
    .target(50.0)
    .mode("auto");

// Аварийный контроль давления теплоносителя
boiler.on("pressureDrop", (pressure) => {
    if (pressure < 0.7) {
        print(`КРИТИЧЕСКАЯ АВАРИЯ: Давление в котле упало до ${pressure} бар!`);
        boiler.burner().enable(false);  // Превентивная блокировка горелки
        buzzer.alarm(true);
    }
});
```

### 4.2. Сценарий 2: Многоконтурный дом с теплыми полами и эмуляцией пульта (BSB / Siemens)
*Оборудование*: Котел Baxi Luna Platinum (Siemens LMS14), радиаторы 2-го этажа, смесительный теплый пол 1-го этажа.
*Задачи*: Раздельные кривые контуров, защита ламината от перегрева, трансляция стороннего Zigbee-датчика температуры гостиной в котел в качестве фирменного регулятора QAA75.

```javascript
// Подключение к шине BSB (Siemens Albatros)
const boiler = BSB.bus(1)
    .pins(17, 16)
    .baud(4800)
    .address(0x42);

// Внешний датчик температуры в гостиной (например, из сети Zigbee/Matter)
const livingRoomSensor = Sensor.get("living_room_temp");

// Контур 1: Радиаторы второго этажа
boiler.circuit(1)
    .comfort(21.5)
    .reduced(18.0)
    .curve(1.30)
    .mode("auto");

// Контур 2: Водяной теплый пол первого этажа со смесителем
boiler.circuit(2)
    .comfort(22.0)
    .curve(0.60)                       // Пологая кривая для инерционного теплого пола
    .maxFlow(40.0)                     // Аппаратное ограничение: не выше 40°C в стяжку пола!
    .influence(0.85)                   // Высокий учет комнатной температуры (Room Influence)
    .emulateRoom(() => livingRoomSensor.value()) // FeOS выступает как пульт Siemens QAA75
    .mode("auto");

// Бойлер косвенного нагрева (БКН) на 200 литров
boiler.dhw()
    .target(55.0)
    .hysteresis(5.0)
    .mode("auto");
```

### 4.3. Сценарий 3: Электрокотел и ночной тариф (eBUS / Protherm Скат)
*Оборудование*: Электрический котел Protherm Скат 14 кВт + бойлер косвенного нагрева.
*Задачи*: Ночной форсированный прогрев бойлера по дешевому тарифу (23:00–07:00), еженедельная термодезинфекция от легионеллы в ночь на воскресенье.

```javascript
const boiler = eBUS.bus(1)
    .pins(21, 22)
    .baud(2400)
    .address(0x10);

// Базовый режим отопления
boiler.circuit(1)
    .comfort(22.0)
    .reduced(18.0)
    .mode("auto");

// Ночной тариф: в 23:00 прогреваем бойлер до 60°C на полной мощности
Cron.schedule("0 23 * * *", () => {
    print("🌙 Начало ночного тарифа: форсированный прогрев бойлера");
    boiler.burner().maxModulation(100);
    boiler.dhw().target(60.0).boost(true);
});

// Утренний переход на дневной экономный режим ГВС в 07:00
Cron.schedule("0 7 * * *", () => {
    print("☀️ Конец ночного тарифа: возвращение к штатным уставкам");
    boiler.burner().maxModulation(50); // Ограничиваем пиковую нагрузку на сеть днем
    boiler.dhw().target(45.0).boost(false);
});

// Еженедельная антилегионелла: каждое воскресенье в 03:00 ночи
Cron.schedule("0 3 * * 0", () => {
    print("🛡️ Профилактика бактерий: запуск цикла антилегионеллы (+65°C)");
    boiler.dhw().antiLegionella(true);
});
```

### 4.4. Сценарий 4: Сценарии присутствия «Дома / В отъезде» (MQTT / Home Assistant)
*Задачи*: Переключение всей котельной в энергосберегающий режим одной кнопкой при уходе из дома и предварительный прогрев перед приездом.

```javascript
const boiler = OpenTherm.bus(1).in(19).out(18);

// Режим «Все ушли / Отпуск»
MQTT.subscribe("home/mode/vacation", (active) => {
    if (active) {
        print("✈️ Режим «В отъезде»: перевод котельной в эко-режим");
        boiler.circuit(1).reduced(16.0).mode("eco");
        boiler.dhw().target(35.0).mode("eco");
    } else {
        print("🏠 Режим «Дома»: комфортный прогрев");
        boiler.circuit(1).comfort(22.0).mode("auto");
        boiler.dhw().target(52.0).mode("auto").boost(true);
    }
});
```

### 4.5. Сценарий 5: Отказоустойчивый каскад «Газ + Резервный электрокотел» (EMS Buderus)
*Оборудование*: Газовый котел Buderus Logamax (EMS), резервный электрокотел, подключенный через силовое контакторное реле FeOS на GPIO 14.
*Задачи*: Мгновенный автоматический ввод резерва при блокировке газового котла или пропадании давления газа.

```javascript
const mainBoiler = EMS.bus(1).pins(4, 5).baud(9600);
const backupRelay = GPIO.output(14).openDrain(false).initial(false);

// Мониторинг аварийного останова основного котла
mainBoiler.on("fault", (code, message) => {
    print(`🚨 КРИТИЧЕСКАЯ АВАРИЯ ГАЗОВОГО КОТЛА [${code}]: ${message}`);
    print("⚡ Запуск резервного электрического котла!");
    
    // Включаем силовой контактор резервного электрокотла
    backupRelay.high();
    
    // Экстренное уведомление инженеру и владельцу
    Push.notify({
        title: "Авария отопления!",
        message: `Газовый котел встал по ошибке ${code}. Введен в работу резервный электрокотел.`,
        priority: "critical"
    });
});
```

### 4.6. Сценарий 6: Полная интеграция с живой мнемосхемой FerrumSCADA (RFC-0008)
*Задачи*: Привязка состояний котла к векторным SVG-элементам дашборда котельной без промежуточного кода.

```javascript
const boiler = BSB.bus(1).pins(17, 16);

// Анимация пламени горелки на мнемосхеме
boiler.burner().on("stateChange", (firing) => {
    SCADA.element("svg_flame")
        .visible(firing)
        .style("opacity", firing ? 1.0 : 0.0);
});

// Динамическое обновление процентов модуляции и шкалы манометра
boiler.on("telemetry", () => {
    SCADA.element("label_flow_temp").text(`${boiler.circuit(1).flowTemp().toFixed(1)} °C`);
    SCADA.element("label_pressure").text(`${boiler.pressure().toFixed(2)} бар`);
    SCADA.element("gauge_modulation").value(boiler.burner().modulation());
    SCADA.element("label_dhw_temp").text(`${boiler.dhw().temp().toFixed(1)} °C`);
});
```

## 🗺️ 5. План реализации в ядре FerrumOS

1. **Фаза 1: Универсальный фасад `BoilerDevice` в `ferrum-runner`**:
   - Описание трейтов `BoilerCircuit`, `BoilerDHW`, `BoilerBurner`, `BoilerTelemetry`.
   - Экспорт унифицированных JS-биндингов во встроенный движок.
2. **Фаза 2: Драйвер BSB/LPB (`ferrum-bsb-core`)**:
   - Аппаратный полудуплекс 4800 8E1, подавление эха, движок 15 типов данных Siemens.
3. **Фаза 3: Драйвер OpenTherm (`ferrum-opentherm-core`)**:
   - Программный/RMT манчестерский трансивер 1000 бод, строгий секундный цикл опроса, преобразование `f8.8` / `u16`.

   - Реализация арбитража шины eBUS (2400 бод) и детекции Break для EMS Buderus (9600 бод).

   - Библиотека готовых анимированных компонентов: котловой блок, горелка с пламенем, смесительные узлы контуров, бойлер с температурным градиентом.
