# Рецепт: Дисплеи E-Paper (Электронные ценники)

`Статус: 🟢 В релизе (v5.0)` • `Чипы: ESP32-C6, ESP32-C3` • `Панели: SSD1680 (1.54", 2.13", 2.9")`

Электронные ценники (ESL) и дисплеи E-Paper (E-Ink) идеально подходят для автономных устройств умного дома: они потребляют энергию **только в момент перерисовки кадра**. Отрисованное изображение сохраняется на экране годами без подачи питания.

---

## 1. Схема подключения

Подключение экранов E-Paper 1.54", 2.13" или 2.9" (GoodDisplay / Waveshare) по шине SPI:

| Пин дисплея | Пин контроллера | Назначение |
|---|---|---|
| **BUSY** | GPIO 4 | Статус готовности (Low = готов) |
| **RESET** | GPIO 5 | Аппаратный сброс |
| **D/C** | GPIO 6 | Выбор Данные / Команда |
| **CS** | GPIO 7 | Выбор ведомого SPI (Chip Select) |
| **SCK** | GPIO 19 | Тактовый сигнал SPI Clock |
| **MOSI** | GPIO 18 | Данные SPI Master Out |

> [!TIP]
> Подавайте питание VCC дисплея через P-канальный MOSFET-ключ. Перед уходом в сон снимайте питание с экрана полностью — это устранит паразитное потребление контроллера дисплея (около 20 мкА).

---

## 2. Инициализация и вывод данных

```javascript
// Настройка дисплея через цепочку методов
const epd = Display.epaper()
    .model("2.9_monochrome")
    .spi(0)
    .pins({ busy: 4, reset: 5, dc: 6, cs: 7 });

// Очистка и отрисовка данных
epd.clear();
epd.drawText(10, 20, "Узел FerrumOS", { size: 2 });
epd.drawText(10, 50, `Темп: ${I2C.bus(0).aht20().readTemperature().toFixed(1)} C`);
epd.drawText(10, 80, `АКБ: ${Power.batteryVoltage().toFixed(2)} В`);

// Обновление экрана (занимает ~2 секунды)
epd.refresh();

// Отключение питания дисплея и сон на 15 минут
Power.sleep()
    .after(15).minutes()
    .enter();
```

---

## 3. Расход оперативной памяти (SRAM)

Монохромные экраны E-Paper требуют всего 1 бит на пиксель:
- **200 × 200 px (1.54")**: 5 000 байт RAM.
- **296 × 128 px (2.9")**: 4 736 байт RAM.

FerrumOS выделяет этот буфер только на время отрисовки и освобождает память перед уходом в сон.
