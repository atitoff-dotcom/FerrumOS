# Справочник АЦП (ADC)

Модуль `ADC` считывает аналоговое напряжение с выделенных пинов с поддержкой аппаратного усреднения и eFuse-калибровки.

---

## Инициализация пина АЦП: `ADC.pin(pin)`

Настраивает пин аналого-цифрового преобразователя. Возвращает объект управления АЦП.

### Пример
<!-- snippet: id="adc_pin" category="Аналоговые датчики (АЦП)" title="Измерение напряжения (АЦП)" icon="fa-chart-line" desc="Считывание физического напряжения в милливольтах с калибровкой чипа." badges="['Диапазон: 0..3.3В', 'eFuse калибровка', 'Multisampling: 16']" -->
```javascript
// Настройка АЦП на GPIO 2
const adc = ADC.pin(2)
    .attenuation("11db") // Диапазон измерения до ~3.3В (входной делитель)
    .samples(16);        // Аппаратное усреднение 16 замеров (фильтр шума)

// Чтение калиброванного напряжения в милливольтах (мВ)
const millivolts = adc.readMilliVolts();
```

---

## Методы цепочки конфигурации

### .attenuation(level: string)
Задает коэффициент ослабления входного сигнала (встроенный делитель напряжения).

| Значение | Диапазон входного напряжения | Назначение |
| :--- | :--- | :--- |
| `"0db"` | 0 .. 1100 мВ | Максимальная точность для слабых сигналов (без делителя) |
| `"2.5db"` | 0 .. 1500 мВ | Промежуточный диапазон |
| `"6db"` | 0 .. 2200 мВ | Сигналы логических уровней 1.8В - 2.0В |
| `"11db"` | 0 .. 3300 мВ | По умолчанию. Полный диапазон питания 3.3В |

### .samples(count: number)
Количество последовательных аппаратных замеров для усреднения (мультисэмплинг / оверсэмплинг).
- **Диапазон**: от `1` (одиночный замер, максимальная скорость) до `64`.
- **Рекомендация**: значение `16` или `32` эффективно подавляет высокочастотный шум радиомодулей (Wi-Fi/Thread).

---

## Методы измерений

### handle.readMilliVolts(): number
Возвращает физическое напряжение в милливольтах (`мВ`).
- В отличие от сырых отсчетов, автоматически применяет заводскую калибровку чипа из памяти eFuse для компенсации нелинейности АЦП.

### handle.readRaw(): number
Возвращает сырое некалиброванное значение 12-битного АЦП (от `0` до `4095`).
