## Стандарт Fluent Chaining (Цепочка методов)

В FerrumOS вся настройка периферии строится **исключительно на цепочках методов (Fluent Chaining)**:

```javascript
// Правильно: Атомарная настройка через цепочку методов
const relay = GPIO.output(15)
    .openDrain(true)
    .pullUp()
    .invert(true)
    .initial(false);
```

### Почему принят этот стандарт
1. **Атомарная инициализация регистров**: Вся цепочка методов сворачивается компилятором в единую команду ядра (`OP_BIND_GPIO` с 1-байтовой битовой маской флагов).
2. **Защита от аппаратных глитчей**: Построчная настройка свойств оставляет пин в промежуточных неопределенных состояниях на десятки микросекунд, что может вызвать ложное срабатывание реле или симисторов.
3. **Нулевой оверхед по памяти**: Цепочки вызовов разрешаются на этапе компиляции и не создают промежуточных объектов в оперативной памяти (Zero Heap).
