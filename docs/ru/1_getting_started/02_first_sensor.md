# Обучение 2: Первый датчик климата (I2C)

`Статус: 🟢 В релизе (v5.0)` • `Чипы: ESP32-C6, ESP32-C3` • `Шина: I2C Master`

В этом уроке вы подключите цифровой датчик температуры и влажности (AHT20 или SHT40) по шине I2C и настроите вывод телеметрии в реальном времени.

---

## Схема подключения

Подключите сенсор к вашей плате по шине I2C:

| Пин датчика | Пин ESP32-C6 / C3 | Назначение |
|---|---|---|
| **VCC** | 3.3V | Питание 3.3 В |
| **GND** | GND | Общий провод (земля) |
| **SDA** | GPIO 18 (C6) / GPIO 4 (C3) | Линия данных I2C Data |
| **SCL** | GPIO 19 (C6) / GPIO 5 (C3) | Линия тактирования I2C Clock |

---

## Скрипт опроса I2C-датчика

Создайте файл `climate.js` в редакторе FerrumOS Studio:

<!-- snippet: id="i2c_sensor_aht20" category="Шины данных (I2C / SPI)" title="Опрос I2C датчика (AHT20)" icon="fa-thermometer-half" desc="Считывание температуры и влажности с калиброванного цифрового датчика AHT20." badges="['I2C 400kHz', 'AHT20', 'Raw Data']" -->
```javascript
// Настройка шины I2C в цепочке методов
const bus = I2C.bus(0)
    .frequency(400000);

// Инициализация сенсора (адрес AHT20: 0x38)
const AHT20_ADDR = 0x38;
bus.writeTo(AHT20_ADDR, [0xBE, 0x08, 0x00]);
delay(20);

// Основной цикл измерений
while (true) {
    // Запуск измерения командой 0xAC, 0x33, 0x00
    bus.writeTo(AHT20_ADDR, [0xAC, 0x33, 0x00]);
    delay(80);

    // Считывание 6 байт сырых данных
    const raw = bus.readFrom(AHT20_ADDR, 6);
    
    // Расчет влажности (20-битное число)
    const rawH = ((raw[1] << 12) | (raw[2] << 4) | (raw[3] >> 4));
    const humidity = (rawH * 100) / 1048576;

    // Расчет температуры (20-битное число)
    const rawT = (((raw[3] & 0x0F) << 16) | (raw[4] << 8) | raw[5]);
    const tempC = ((rawT * 200) / 1048576) - 50;

    // Отправка телеметрии в консоль FerrumOS Studio
    System.log(`Температура: ${tempC.toFixed(1)}°C, Влажность: ${humidity.toFixed(1)}%`);

    delay(2000);
}
```

---

## Проверка работы

1. Нажмите **Run** (`Ctrl+Enter`).
2. В окне телеметрии каждые 2 секунды будут появляться точные климатические замеры.
3. Если провод отойдет или на шине произойдет сбой (NACK), аппаратный уровень FerrumOS вернет безопасную ошибку без зависания всей операционной системы.
