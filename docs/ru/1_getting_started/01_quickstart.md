# Обучение 1: Быстрый старт (Zero to Hero)

`Статус: 🟢 В релизе (v5.0)` • `Чипы: ESP32-C6, ESP32-C3, BL702` • `Инструмент: FerrumOS Studio 5.0`

Добро пожаловать в FerrumOS! Это пошаговое руководство проведет вас от распаковки микроконтроллера на архитектуре RISC-V до запуска вашего первого скрипта автоматизации менее чем за 5 минут.

---

## Необходимое оборудование и подготовка

Вам понадобятся:
- Отладочная плата **ESP32-C6** (рекомендуется для Thread + Wi-Fi), **ESP32-C3** или **BL702**.
- Кабель USB-C для подключения к компьютеру.
- Браузер с поддержкой Web Serial (Chrome, Edge) или автономное приложение **FerrumOS Studio** (`FerrumOS-Studio.exe`).

---

## Шаг 1: Запуск FerrumOS Studio

1. Запустите `FerrumOS-Studio.exe` (или откройте веб-интерфейс Studio по адресу `http://localhost:8080`).
2. Подключите вашу плату к компьютеру кабелем USB-C.
3. В верхней панели Studio нажмите кнопку **Подключить (Connect)** и выберите COM-порт вашего устройства.

---

## Шаг 2: Прошивка ядра в 1 клик

Если на плате еще не установлена FerrumOS:
1. Перейдите во вкладку **Flasher** в Studio.
2. Выберите модель чипа: **ESP32-C6** (или ESP32-C3).
3. Выберите профиль мощности передатчика: **Balanced (8 dBm)** или **Eco (4 dBm)**.
4. Нажмите кнопку **Flash Firmware**. Studio автоматически прошьет загрузчик, таблицу разделов и ядро FerrumOS прямо через Web Serial.

После завершения прошивки плата перезагрузится, и в дашборде Studio загорится зеленый индикатор статуса узла.

---

## Шаг 3: Написание первого скрипта

Перейдите во вкладку **IDE / Скрипты**. Создайте новый файл `blink.js` и вставьте следующий код:

<!-- snippet: id="delay_timing" category="Циклы и задержки" title="Мигание и задержка (Blink)" icon="fa-clock" desc="Периодический цикл переключения выхода с задержкой delay(ms)." badges="['Main Loop', 'delay(500)', 'Fluent Chaining']" -->
```javascript
// Атомарная настройка светодиода на GPIO 8 через Fluent Chaining
const led = GPIO.output(8)
    .pullUp()
    .invert(true)
    .initial(false);

// Цикл периодического мигания
while (true) {
    led.write(true);
    delay(500);
    led.write(false);
    delay(500);
}
```

> [!NOTE]
> Обратите внимание на цепочку методов: `GPIO.output(8).pullUp().invert(true).initial(false)`. В FerrumOS принят строгий стандарт **Fluent Chaining** — он гарантирует атомарную настройку регистров и исключает аппаратные глитчи на пинах.

---

## Шаг 4: Загрузка и запуск

1. Нажмите кнопку **Run** (или сочетание клавиш `Ctrl+Enter`).
2. Компилятор Studio за 2 миллисекунды соберет JavaScript в компактный байткод FerrumOS и передаст его в память чипа.
3. Светодиод на плате начнет мигать с интервалом в 500 мс.
4. В нижней панели **Телеметрия** появятся логи работы и частота циклов в реальном времени.

Поздравляем! Вы запустили свою первую задачу в FerrumOS. Переходите к следующему уроку: [Обучение 2: Первый датчик климата](02_first_sensor.md).
