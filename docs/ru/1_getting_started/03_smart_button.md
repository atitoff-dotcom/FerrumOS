# Обучение 3: Умная кнопка и жесты

`Статус: 🟢 В релизе (v5.0)` • `Чипы: ESP32-C6, ESP32-C3` • `Ядро: Аппаратный ButtonDetector`

В обычных микроконтроллерах для распознавания клика, двойного клика и удержания кнопки приходится писать громоздкие конечные автоматы. В FerrumOS распознавание жестов вынесено прямо в ядро Rust (`ButtonDetector`) и выполняется аппаратно с нулевой нагрузкой на процессор.

---

## Схема подключения

Подключите тактовую кнопку между пином **GPIO 9** (штатная кнопка BOOT на большинстве плат ESP32) и **GND**.

---

## Настройка умной кнопки

Создайте файл `smart_button.js`:

<!-- snippet: id="btn_smart_gestures" category="Кнопки / Входы" title="Умная кнопка (Click, Double, Hold)" icon="fa-hand-pointer" desc="Аппаратный детектор жестов: одиночный клик, двойной клик, длинное удержание." badges="['Smart Button', '4 события', 'Zero-CPU wait']" -->
```javascript
// Настройка светодиода индикации
const led = GPIO.output(8)
    .pullUp()
    .invert(true)
    .initial(false);

// Атомарная настройка аппаратного детектора жестов на GPIO 9
const btn = GPIO.input(9)
    .pullUp()
    .button()
    .clickMs(350)
    .doubleClickMs(250)
    .longPressMs(800);

System.log("Детектор жестов запущен...");

while (true) {
    // Ожидание подтвержденного жеста от ядра ОС
    const event = btn.wait();

    if (event === Button.CLICK) {
        System.log("Жест: Одиночный клик -> Переключение LED");
        led.write(!led.read());
    } else if (event === Button.DOUBLE_CLICK) {
        System.log("Жест: Двойной клик -> Тройное мигание");
        for (let i = 0; i < 3; i++) {
            led.write(true);
            delay(100);
            led.write(false);
            delay(100);
        }
    } else if (event === Button.LONG_PRESS) {
        System.log("Жест: Длинное удержание -> Сброс состояния");
        led.write(false);
    }
}
```

---

## Таблица событий и жестов

| Константа события | Описание | Значение тайминга |
|---|---|---|
| `Button.CLICK` | Одиночное быстрое нажатие и отпускание | `clickMs(350)` |
| `Button.DOUBLE_CLICK` | Два последовательных нажатия подряд | `doubleClickMs(250)` |
| `Button.LONG_PRESS` | Удержание кнопки дольше заданного порога | `longPressMs(800)` |
| `Button.RELEASE` | Отпускание кнопки после длинного удержания | Мгновенно |

---

## Почему аппаратный детектор эффективнее

В обычных прошивках антидребезг делается в программном цикле, что разряжает батарейку и приводит к пропуску кликов во время сетевого обмена. В FerrumOS конечный автомат кнопки обрабатывается в аппаратном прерывании ядра, а скрипт просыпается **только в момент свершившегося жеста**.
