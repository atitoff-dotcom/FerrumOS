# Руководство по управлению парком устройств и пинами (`tools/fleet_manager.py`)

**FerrumOS Fleet Manager** — это централизованная утилита оркестрации на Python, предназначенная для управления, валидации и развертывания скриптов Rhai/JS на множестве узлов FerrumOS IoT.

---

## 🏗️ Основные обязанности

1. **Централизованный реестр устройств (`tools/fleet.json`):**
   Ведет глобальный учет всех узлов ESP32-C6 в системе умного дома (IP-адреса, HTTP-порты, описания).

2. **Предварительная валидация конфликтов аппаратных пинов:**
   Анализирует код скриптов Rhai/JS *до* передачи по сети, гарантируя, что аппаратные пины (GPIO, I2C SDA/SCL) не заняты параллельными скриптами на том же узле.

3. **Автоматическое разрешение зависимостей драйверов (`import "drivers/..."`):**
   Парсит директивы `import "drivers/<name>"` в пользовательских скриптах. Если скрипт использует файл драйвера из `drivers/` (например, `drivers/mhz19b.rhai`), Fleet Manager автоматически загружает нужный драйвер на узел перед развертыванием скрипта.

4. **Мгновенное развертывание скриптов по OTA:**
   Отправляет проверенные скрипты на узлы через HTTP REST API (`POST /api/scripts`) менее чем за 0.1 секунды.

5. **Мониторинг состояния парка устройств:**
   Агрегирует статусы исполнения (`LOADED`, `RUNNING`, `FAILED`) и счетчики запусков по всем зарегистрированным узлам.

## 💻 Руководство по работе с CLI

### 1. Проверка состояния парка устройств
Проверяет сетевую доступность и статусы скриптов на всех узлах:

```bash
python tools/fleet_manager.py status
```

### 2. Валидация привязок пинов скрипта (предварительная проверка)
Проверяет динамические привязки пинов без развертывания на узле:

```bash
python tools/fleet_manager.py validate path/to/script.rhai
```

### 3. Развертывание скрипта по OTA на конкретный узел
Выполняет валидацию и развертывает скрипт на указанный узел:

```bash
python tools/fleet_manager.py deploy living_room_gateway climate_ctrl path/to/script.rhai
```
