# FerrumOS: Электронные ценники (ESL) и ультранизкое энергопотребление

Электронные ценники (**ESL — Electronic Shelf Labels**) представляют собой специализированный класс ультрабюджетных автономных IoT-устройств торговой автоматизации с требованиями по сроку службы **10+ лет на одной батарейке CR2032/CR2450**.

---

## 🏷️ 1. Архитектурный обзор ESL-ценника FerrumOS

```
┌────────────────────────────────────────────────────────────────────────┐
│ 1. Сервер Магазина / Python Fleet Orchestrator                         │
├────────────────────────────────────────────────────────────────────────┤
│ Генерация ценников, промо-акций и штрихкодов -> Отправка по BLE Mesh   │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ BLE 5.0 Mesh / Thread Broadcast
┌───────────────────────────────────▼────────────────────────────────────┐
│ 2. Электронный ценник (BL702 / TLSR8258 + E-Paper + FerrumOS)            │
├────────────────────────────────────────────────────────────────────────┤
│ - Процессор: Bouffalo Lab BL702 / BL706 (32-bit RISC-V @ 1.0 мкА)      │
│ - Дисплей: E-Paper / E-Ink (Потребление 0.00 мкА в статике)            │
│ - Операционная система: FerrumOS (Sub-1 µA Power Manager + Rhai/JS)     │
└────────────────────────────────────────────────────────────────────────┘
```

## ⚡ 2. Энергопотребление и расчёт 10-летней автономии (CR2032)

### 📊 Исходные параметры:
* **Емкость батарейки CR2032:** 220 мА·ч (220 000 мкА·ч).
* **Ток в режиме глубокого сна (BL702 PDS15 c RTC 32.768 кГц):** **1.0 мкА**.
* **Интервал авто-пробуждения:** Каждые 3 часа (8 раз в сутки).
* **Ток и время активной фазы:** 15 мА в течение 1.0 сек (прием BLE-пакета и отрисовка E-Paper дисплея по SPI).

### 🧮 Расчёт суточного баланса энергии:
1. **Расход в глубоком сне (1.0 мкА):**  
   $$1.0 \text{ мкА} \times 24 \text{ часа} = 24 \text{ мкА·ч / день}$$

2. **Расход на 8 просыпаний в сутки:**  
   $$\frac{8 \text{ раз} \times 1.0 \text{ сек} \times 15\,000 \text{ мкА}}{3600 \text{ сек}} \approx 33.3 \text{ мкА·ч / день}$$

3. **Суммарный суточный расход:**  
   $$24 + 33.3 = \mathbf{57.3 \text{ мкА·ч / день}}$$

4. **Итоговый срок службы на одной батарейке CR2032:**  
   $$\text{Срок службы} = \frac{220\,000 \text{ мкА·ч}}{57.3 \text{ мкА·ч / день}} = 3839 \text{ дней} \approx \mathbf{10.5 \text{ лет!}}$$

## 🔌 3. Схема дискретной защелки полного обесточивания ($0.02)

Для базовых чипов без нативного RTC-сна используется альтернативная транзисторная схема защелки **$0.02** (в 20 раз дешевле TPL5110):

```text
  +3.3V (Батарейка CR2032)
    │
    ├─────────────────────────────┐
    │                             │
   ┌┴┐ R1                        ┌┴┐
   │ │ 100kΩ                     │ │ R4 100kΩ
   └┬┘                           └┬┘
    │    ┌──────────────────┐     │
    ├───┤G  Q1 (AO3401A)  S├─────┼─────────────┐
    │   │   P-MOSFET       │     │             │
    │   └────────┬─────────┘    ┌┴┐ RTC /      │
    │            │D             o o Reed       │
    │            ▼               │ (Trigger)   │
    │     [ MCU VCC Pin ]        ├─────┐       │
    │                            │     │       │
    │                           ┌┴┐   ┌┴┐      │
    │                        D1 │ ∇   │ │ R2   │
    │                           └┬┘   └┬┘ 10kΩ │
    │   ┌──────────────────┐     │     │       │
    └───┤C  Q2 (2N3904)   B├─────┴─────┼───────┼──────────────┐
        │   NPN BJT        │           │       │              │
        └────────┬─────────┘          ┌┴┐     ┌┴┐             │
                 │E                   │ │ R3  │ │ R5          │
                 │                    │ │100kΩ│ │100kΩ        │
                ═╧═ GND               └┬┘     └┬┘             │
                                       │       │              │
                                      ═╧═     ═╧═            ═╧═
                                      GND     GND            GND
                                                              ▲
                                                              │
                                            [ MCU GPIO_HOLD Pin ]
```

### Назначение компонентов ($0.022):
- **Q1 (AO3401A P-MOSFET):** Силовой P-канальный MOSFET коммутации 3.3V ($0.012).
- **Q2 (2N3904 NPN BJT):** Управляющий транзистор затвора ($0.005).
- **D1 (1N4148 / BAT54):** Разделительный диод цепи триггера ($0.003).
- **R1-R5:** Подтягивающие резисторы 0402 ($0.002).

## ⏰ 3.1. Использование микросхемы часов PCF85063 ($0.08, 0.22 мкА)

Для базовых чипов (например, BL602 без нативного 1.0 мкА RTC-сна) в цепь триггера `Trigger` подключается ультрабюджетная часовая микросхема **PCF85063 (NXP / китайский аналог)**:

* **Стоимость:** **~$0.08** (в партии).
* **Собственное потребление:** всего **0.22 мкА**!
* **Принцип работы:** 
  1. Часы PCF85063 работают постоянно от батарейки CR2032 (0.22 мкА).
  2. Процессор полностью обесточен (0.00 мкА).
  3. Каждые 3 часа (10 800 секунд) пин прерывания `INT` микросхемы PCF85063 подает короткий импульс на базу `Q2`, открывая питание `Q1` и запуская микроконтроллер.
  4. После завершения работы процессор перенастраивает таймер PCF85063 по шине I2C и снимает сигнал `PowerHoldPin`, обесточивая схему.

## 💻 4. Пример Rhai/JS Скрипта Управления Ценником

```javascript
// 1. Первой строчкой при старте фиксируем пин защелки питания!
bind_gpio_output("PowerHoldPin", 4);
device.gpio("PowerHoldPin").write(true);

console.log("ESL Ценник проснулся. Чтение обновлений...");

try {
    // 2. Инициализация E-Ink дисплея по SPI
    bind_spi_bus("EInkSPI", 11, 12, 13);
    
    // 3. Проверка BLE-пакета от сервера магазина
    let ble_data = mqtt.publish("ferrumos/esl/check_price", "Node_01");

    // 4. Отрисовка обновленной цены на E-Paper экране
    console.log("Обновление цены на E-Paper дисплее...");
    device.spi("EInkSPI").transfer([0x24, 0x19, 0x99]); // Команда перерисовки E-Ink

} catch (err) {
    console.error("Ошибка обновления ценника: " + err);
}

// 5. Завершение работы: отпускаем ножку питания для ухода в 0.00 мкА
console.log("Завершение работы. Обесточивание...");
device.gpio("PowerHoldPin").write(false);
```

## 🔬 5. Выбор микроконтроллера BL702L и Экономика Закупок (1000 шт.)

Для серийного производства ценников идеальным выбором являются чипы с корпусировкой **SiP (System-in-Package)**, где кристалл 512 КБ / 1 МБ Flash интегрирован прямо внутрь корпуса микроконтроллера.

### 💰 Оптовые цены на чипы со встроенным Flash (партия от 1 000 шт.):

| Модель чипа | Архитектура & Встроенный Flash | Цена за 1 шт. (партия 1000 шт.) |
| :--- | :--- | :--- |
| **BL702L** | 32-bit RISC-V @ 192MHz, **512 KB SiP Flash**, BLE 5.0 / Thread | **$0.48 – $0.55** |
| **BL704L** | 32-bit RISC-V @ 192MHz, **1 MB SiP Flash**, QFN32 | **$0.58 – $0.65** |
| **BL706L** | 32-bit RISC-V @ 192MHz, **2 MB SiP Flash**, QFN40 | **$0.68 – $0.78** |

### 🎯 Преимущества SiP-корпусировки BL702L для FerrumOS:
1. **Отсутствие отдельной микросхемы флеш-памяти на плате:** Экономит место на печатной плате и $0.15 стоимости BOM.
2. **Нулевой ток утечки флеш-памяти в сне:** Встроенный SiP Flash переходит в отсечку вместе с процессором, обеспечивая нативный сон **1.0 мкА** с активным RTC.
3. **Объем 512 КБ Flash:** Полностью вмещает ядро FerrumOS Core на Rust (~300 КБ) и скрипты автоматизации Rhai/JS (2–5 КБ).
