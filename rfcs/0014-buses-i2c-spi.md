# RFC 0014: Цифровые шины данных — I2C и SPI Master

Статус: Implemented  
Версия ядра: 0.6.0+

---

## Реализовано

### 1. Архитектура и принципы
- **Аппаратные контроллеры без битовой эмуляции (Hardware Controllers)**: шины I2C и SPI используют аппаратные блоки ESP32-C6 с поддержкой FIFO и прерываний.
- **Поддержка Repeated Start в I2C**: корректное чтение внутренних регистров датчиков без освобождения шины между фазой записи адреса и фазой чтения данных.
- **Гибкая конфигурация скорости**: I2C поддерживает стандартный (100 кГц) и быстрый (400 кГц) режимы. SPI поддерживает частоты до 40 МГц.
- **Защита от зависаний шины**: тайм-ауты транзакций с автосбросом шины I2C (clock toggling) при блокировке ведомым устройством.

### 2. Спецификация Fluent JS API и проверенные сниппеты

#### 2.1 Шина I2C (Чтение регистра)
<!-- snippet: id="i2c_bus" category="Шины данных (I2C / SPI)" title="Шина I2C (Чтение регистра)" icon="fa-microchip" desc="Инициализация шины I2C и чтение регистра данных датчика." badges="['I2C Master', '100kHz', 'Repeated Start']" -->
```javascript
// Атомарная инициализация аппаратного I2C Master
const i2c = I2C.bus(0)
    .pins({ sda: 18, scl: 19 })
    .frequency(100000); // 100 kHz

// Чтение 2 байт из регистра 0x00 устройства 0x38 (AHT20 / BMP280)
const data = i2c.readFrom(0x38, 0x00, 2);
```

#### 2.2 Опрос I2C датчика (AHT20)
<!-- snippet: id="i2c_sensor_aht20" category="Шины данных (I2C / SPI)" title="Опрос I2C датчика (AHT20)" icon="fa-thermometer-half" desc="Считывание температуры и влажности с калиброванного цифрового датчика AHT20." badges="['I2C 400kHz', 'AHT20', 'Raw Data']" -->
```javascript
const i2c = I2C.bus(0).pins({ sda: 18, scl: 19 }).frequency(400000);

// Запуск измерения AHT20
i2c.writeTo(0x38, [0xAC, 0x33, 0x00]);
delay(80);

// Чтение 6 байт калиброванных данных
const raw = i2c.readFrom(0x38, 6);
const humidity = ((raw[1] << 12) | (raw[2] << 4) | (raw[3] >> 4)) * 100 / 1048576;
const temp = ((((raw[3] & 0x0F) << 16) | (raw[4] << 8) | raw[5]) * 200 / 1048576) - 50;
```

#### 2.3 Полнодуплексный обмен по шине SPI
<!-- snippet: id="spi_bus" category="Шины данных (I2C / SPI)" title="Шина SPI (Транзакция)" icon="fa-network-wired" desc="Полнодуплексный обмен байтами по шине SPI." badges="['SPI Master', '10MHz', 'Full-Duplex']" -->
```javascript
// Инициализация SPI шины
const spi = SPI.bus(1)
    .pins({ sck: 4, mosi: 6, miso: 5, cs: 7 })
    .frequency(10000000) // 10 MHz
    .mode(0);

// Передача байтов и одновременный прием ответа
const response = spi.transfer([0x9F, 0x00, 0x00, 0x00]);
```

## Планируется

1. **Режим I2C Slave**:
   - Работа модуля FerrumOS как эмулятора I2C датчика или периферийного сопроцессора для внешних систем.
2. **Аппаратный SPI DMA**:
   - Высокоскоростная передача графических фреймбуферов на дисплеи (ST7789, ILI9341, E-Paper) со скоростью до 40–80 МГц без нагрузки на вычислительное ядро.
3. **Автосканирование I2C в Studio**:
   - Кнопка «Сканировать I2C» в панели Studio с автоматическим определением адресов подключенных чипов.
