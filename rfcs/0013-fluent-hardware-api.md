# RFC 0013: Базовая аппаратная периферия — GPIO Выходы, АЦП, ШИМ WS2812 и тайминги

Статус: Implemented  
Версия ядра: 0.6.0+

---

## Реализовано

### 1. Архитектура и принципы
- **Атомарная цепочка методов (Fluent Chaining)**: вся аппаратная периферия настраивается в единой цепочке вызовов без промежуточных мутаций (`pin.open_drain = true` строго запрещено).
- **Zero-Glitch на пинах**: регистры контроллера конфигурируются атомарно перед снятием блокировки вывода, что исключает броски питания на реле и светодиодах при старте.
- **Аппаратный тайминг WS2812 (RMT / SPI MOSI)**: генерация сигналов 800 кГц без задержек главного процессора с аппаратным сбросом `> 50 мкс`.
- **Калиброванный АЦП (SAR ADC)**: заводские поправки из eFuse чипа считываются автоматически; пользователь получает физическое напряжение в милливольтах (`mV`), а не сырые попугаи АЦП.

### 2. Спецификация Fluent JS API и проверенные сниппеты

#### 2.1 Цифровой выход / Реле
<!-- snippet: id="gpio_output" category="Выходы / Реле" title="Реле / Цифровой выход" icon="fa-lightbulb" desc="Атомарная инициализация и управление дискретным выходом (реле, светодиод)." badges="['Digital Out', 'Push-Pull / Open-Drain']" -->
```javascript
// Атомарная инициализация выхода на GPIO15
const relay = GPIO.output(15)
    .openDrain(false)
    .invert(false)
    .initial(false);

// Управление состоянием
relay.high();
delay(100);
relay.low();
```

#### 2.2 Аналого-цифровой преобразователь (АЦП)
<!-- snippet: id="adc_pin" category="Аналоговые датчики (АЦП)" title="Измерение напряжения (АЦП)" icon="fa-chart-line" desc="Считывание физического напряжения в милливольтах с калибровкой чипа." badges="['Диапазон: 0..3.3В', 'eFuse калибровка', 'Multisampling: 16']" -->
```javascript
// Настройка АЦП на пине GPIO3 с усреднением 16 замеров
const sensor = ADC.pin(3)
    .attenuation(11)     // Диапазон до 3.3В (11 dB)
    .samples(16);        // Аппаратный мультисэмплинг

// Получение напряжения с учетом eFuse калибровки чипа
const mv = sensor.readMilliVolts();
```

#### 2.3 Адресные светодиоды WS2812 (Статичный цвет)
<!-- snippet: id="ws2812_rgb" category="RGB WS2812" title="Статичный цвет WS2812" icon="fa-palette" desc="Прямая установка цвета RGB на адресном светодиоде." badges="['WS2812B', 'RGB 0-255', 'Pin 8']" -->
```javascript
// Инициализация адресного светодиода на встроенном пине GPIO8
const led = WS2812.pin(8)
    .count(1)
    .brightness(50); // Яркость 0..100%

// Установка цвета: Красный=0, Зеленый=255, Синий=128
led.setColor(0, 255, 128);
```

#### 2.4 Адресные светодиоды WS2812 (Плавная радуга)
<!-- snippet: id="ws2812_rainbow" category="RGB WS2812" title="Плавная радуга WS2812" icon="fa-rainbow" desc="Циклический перебор цветов на светодиоде в бесконечном цикле." badges="['Анимация', 'Спектр', 'WS2812B']" -->
```javascript
const strip = WS2812.pin(8).count(1).brightness(40);
let hue = 0;

while (true) {
    strip.setHSV(hue, 255, 255);
    hue = (hue + 2) % 360;
    delay(20);
}
```

#### 2.5 Базовый цикл и задержка
<!-- snippet: id="delay_timing" category="Циклы и задержки" title="Мигание и задержка (Blink)" icon="fa-clock" desc="Периодический цикл переключения выхода с задержкой delay(ms)." badges="['Main Loop', 'delay(500)', 'Fluent Chaining']" -->
```javascript
const led = GPIO.output(8).initial(false);

while (true) {
    led.toggle();
    delay(500);
}
```

## Планируется

1. **Аппаратный генератор ШИМ (LEDC / MCPWM)**:
   - Поддержка сервоприводов с прецизионной частотой 50 Гц (длина импульса 1000–2000 мкс).
   - Аппаратное диммирование светодиодов без загрузки CPU на частотах до 20 кГц.
2. **Аппаратно-ускоренный DMA-буфер анимаций WS2812**:
   - Длинные светодиодные ленты (> 300 диодов) с потоковой передачей кадров из Flash.
3. **Режим непрерывного сэмплирования АЦП по таймеру (Continuous ADC DMA)**:
   - Высокоскоростной опрос токовых трансформаторов и аудиосигналов с частотой до 20 кГц.
