# RFC 0016: Реактивные сигналы и межскриптовое взаимодействие (Zero-Copy IPC)

Статус: Implemented  
Версия ядра: 0.6.0+

---

## Реализовано

### 1. Архитектура и принципы
- **Локальная шина сигналов (Zero-Copy Local IPC)**: передача дискретных состояний и числовых значений между независимыми процессами в общей оперативной памяти чипа.
- **Мгновенное пробуждение (Zero-Buffer Signal)**:
  - Задачи-подписчики засыпают на системном примитиве ожидания и мгновенно пробуждаются за доли микросекунды при мутации сигнала.
  - Потребление оперативной памяти: 0 байт на буферизацию очередей; исключены задержки и переполнения FIFO.
- **Изоляция сбоев**: аварийный останов скрипта-обработчика не влияет на скрипты-источники сигналов.

### 2. Спецификация Fluent JS API и проверенные сниппеты

#### 2.1 Объявление реактивного сигнала
<!-- snippet: id="signal_declare" category="Циклы и задержки" title="Реактивный сигнал (IPC)" icon="fa-bolt" desc="Создание общего реактивного сигнала для межскриптового взаимодействия." badges="['IPC', 'Zero-Copy']" -->
```javascript
// Объявление глобального сигнала в памяти контроллера
const lightState = Signal.create("living_room/light", false);

// Обновление состояния (уведомляет всех подписчиков мгновенно)
lightState.set(true);
```

#### 2.2 Асинхронный подписчик сигнала (`.watch`)
<!-- snippet: id="signal_watch" category="Циклы и задержки" title="Подписчик сигнала (.watch)" icon="fa-eye" desc="Асинхронная подписка на изменение сигнала без нагрузки на CPU." badges="['Reactive', 'Sleep']" -->
```javascript
const lightState = Signal.bind("living_room/light");
const relay = GPIO.output(15).initial(false);

// Реактивный слушатель: скрипт спит и просыпается только по изменению
lightState.watch((val) => {
    if (val) {
        relay.high();
    } else {
        relay.low();
    }
});
```

## Планируется

1. **Персистентные сигналы (NVS-backed Signals)**:
   - Автоматическое сохранение последнего состояния выбранных сигналов в энергонезависимой Flash-памяти контроллера.
2. **Транзитные распределенные сигналы (CAN-bridged Signals)**:
   - Прозрачное распространение сигналов между платами по шине CAN 2.0B без явного написания сетевого кода.
3. **Виртуальные вычисляемые сигналы (Computed Signals / Math expressions)**:
   - Декларативное связывание: `const avgTemp = Signal.computed([t1, t2], (a, b) => (a + b) / 2)`.
