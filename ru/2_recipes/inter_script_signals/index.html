    Межскриптовое взаимодействие и реактивные сигналы¶

    FerrumOS позволяет исполнять несколько независимых JavaScript-задач одновременно на одном микроконтроллере. Вместо небезопасных глобальных переменных и блокировок задачи взаимодействуют через неблокирующую событийную шину реактивных сигналов (state.signal).

    🎯 Архитектурный паттерн: разделение обязанностей¶

      ┌───────────────────────────┐         ┌───────────────────────────┐
  │ Задача 1: Датчик климата  │         │ Задача 2: Управление реле │
  │ • Читает АЦП или I2C      │         │ • Ожидает изменений       │
  │ • Обновляет сигнал темп.  │         │ • Управляет вентилятором  │
  └─────────────┬─────────────┘         └─────────────▲─────────────┘
                │                                     │
                │ temp = 27.5                         │ .watch((val) => ...)
                ▼                                     │
  ═══════════════════════════════════════════════════════════════════
                   Реактивная шина сигналов FerrumOS IPC
  ═══════════════════════════════════════════════════════════════════

    1. Скрипт-источник: опрос датчика (sensor.js)¶

    Скрипт-источник считывает показания с физического вывода и передает их в шину сигналов:

    // Объявление разделяемого климатического сигнала
const tempSignal = state.signal("room/temperature", 22.0)
    .exposeHA("sensor", { name: "Температура в комнате", unit: "°C" });

// Настройка аналогового входа на пине 4 с оверсэмплингом
const sensor = ADC.input(4)
    .attenuation(11)
    .samples(32);

while (true) {
    const rawMv = sensor.readMv();
    const tempC = (rawMv - 500) / 10.0; // Формула сенсора TMP36

    // Публикация в шину IPC (генерирует OP_SIGNAL_SET)
    tempSignal = tempC;

    // Сон задачи на 5 секунд
    power.sleepMs(5000);
}

    2. Скрипт-потребитель: управление нагрузкой (actuator.js)¶

    Скрипт-потребитель ничего не знает о регистрах АЦП и физических пинах датчика. Он только отслеживает состояние сигнала:

    // Подключение к тому же топику сигнала
const tempSignal = state.signal("room/temperature");

// Реле управления вентилятором охлаждения
const fan = GPIO.output(15)
    .openDrain(false)
    .initial(false);

// Реактивный подписчик: 0% нагрузки на CPU до изменения температуры
tempSignal.watch((val) => {
    if (val > 28.0) {
        fan.write(true);  // Включить охлаждение
    } else if (val < 25.0) {
        fan.write(false); // Выключить охлаждение
    }
});

    3. Распределенный обмен по шине CAN¶

    Чтобы транслировать этот же сигнал на другие физические контроллеры по двухпроводной витой паре CAN:

    // Автоматическая трансляция изменений сигнала в кадры CAN
const sharedAlarm = state.signal("facility/alarm", false)
    .can(100)
    .urgent();

    Любая плата в сети CAN, запустившая цикл .watch() по топику facility/alarm, мгновенно проснется и обработает событие без сетевых задержек.
